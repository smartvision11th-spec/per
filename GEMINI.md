# Website Generation & UI/UX Guidelines

Whenever the user asks to generate, design, retheme, or build a website, web application, landing page, or frontend interface:

1. **Apply UI/UX Pro Max Skill**:
   - Follow the design intelligence guidelines from the `ui-ux-pro-max` skill.
   - Define a solid design system before writing code: select a purposeful UI style (e.g., modern minimalism, bento grid, etc.), an industry-appropriate color palette, curated typography pairings, responsive layouts, and accessibility standards (WCAG contrast, 44x44px touch targets).

2. **Utilize 21st.dev MCP Tools**:
   - Query the `21st` MCP server tools to search, discover, and retrieve production-grade React and Tailwind CSS components from the 21st.dev library.
   - Integrate the retrieved 21st.dev components into the UI while keeping them consistent with the UI/UX Pro Max design system tokens and theme.
